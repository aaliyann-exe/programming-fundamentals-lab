# Programming Fundamentals

C++ assignments for Programming Fundamentals lab, 1st semester.

Each lab day has its own folder containing the source files, pseudocode and flowcharts (where required; and mostly in .docx form) for that week's tasks.

## Accessing

The assignments are organized in folders by Lab and number. So Lab01 is Lab-01's assignment, and so on. Just open the folder and it'll have the assignment files (in .cpp) !!!

## Compiling

Each file is standalone and compiles with any C++ compiler:

    g++ taskName.cpp -o taskName
    ./taskName

On Windows with Visual Studio, open the `.cpp` file directly and run.

## Notes

Written using only the constructs covered up to that point in the
course, so earlier labs deliberately avoid functions, arrays, or any other ways to write more efficient code.
